# 公共技能安装时拉取

用户已批准按建议方案实现、测试、提交并推送；不发布 npm，不新建分支。

公共引擎在安装/更新时从 ai-skills 拉取最新正式语义版本 Tag；首次 clone，后续 fetch。源码存放专用缓存，安装仍复制并保留现有覆盖保护。选择技能前刷新列表，显示 Tag 和提交。失败后只有用户明确选择才使用可验证的旧缓存；无缓存则停止该次安装。卸载和 --version 无技能联网需求。

包身份与技能来源分离；packageRoot 继续供包装器版本查询使用。移除打包公共技能和构建时下载钩子。包装器 复用引擎，其内部技能行为不变。因不发布 npm，包装器 暂用精确 Git 提交依赖；后续正式发版可换回 npm 版本。

备选：继续内置会使更新依赖 helper 发版；跟随 main 会引入未发布技能；源目录软链会改变现有安装生命周期。采用正式 Tag + 复制。
